What we would do next

Realistic improvements, most important first.

These follow from the gaps in our Well-Architected review. Reorder or replace them based on what you actually observed.
  1. Remove the single point of failure, cheaply. Daily EBS snapshots with AWS Backup and an Auto Scaling group of one instance, so a dead server is replaced automatically and recovery no longer depends on us. Improves Reliability; small extra cost.
  2. Protect the front door. AWS WAF rate-based rule on CloudFront and a secret origin header checked by nginx, so only our distribution can reach the server and floods cannot exhaust the model quota.
  3. Close the feedback loop. A weekly summary e-mail of thumbs-down answers and the most-asked questions without good answers, so the salon can fix its content. Uses data LibreChat already stores.
  4. Better answers for numbers. Pre-computed discount prices in the knowledge base (or a small price-lookup tool), because arithmetic questions are where the model fails most.
  5. A real domain name. Route 53 + ACM certificate, so customers see a salon address instead of cloudfront.net.
